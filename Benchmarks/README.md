# 🧪 Evaluation & Tests

This directory contains the testing suite and benchmark scripts used to evaluate the project's performance and results as part of the master's/bachelor's thesis.

> **Language Notice:**  
> In-code comments and generated output files/datasets are written in **Italian**, matching the primary language of the thesis document.
